2. 手書きでコードを書く際の文字区別（重要）
      * 原則として「筆記体」を使わない。
      * 混同しやすい文字は、手書きテストやノートで間違えないよう別の字体・記号で明確に書き分ける。
文字の書き分けルール一覧
対象文字
	書き分けの注意点・形状
	l (エル) / I (アイ) / 1 (数字) / 7 (ナナ)
	・l（小文字エル）：曲線を意識
・I（大文字アイ）：上下にセリフ（横線）をつける
・1（数字の1）：まっすぐの縦線
・7（ナナ）：斜めに書く
	O (大文字オー) / 0 (数字ゼロ) / D (大文字ディー)
	・0（ゼロ）：斜線を入れる（$\emptyset$ や $\varnothing$ のように記述）
・O と D の形状の違いを明確にする
	+ (プラス) / t (小文字ティー)
	・t：下部をはねさせて書く
	2 (数字) / Z (ゼット)
	・Z：中央に横線を入れて区別する ()
	9 (数字) / q (小文字) / g (小文字)
	・9：数字の9
・q と g はテールの曲げ方で書き分ける
	5 (数字) / S (大文字)
	・5：角を意識して書く
・S：丸みを持たせる（小文字は使わない）
	u (小文字) / v (小文字)
	・u：底面に丸みを持たせ、右下に縦線
・v：底面を尖らせる
	その他誤解しやすい文字
	x と X / K と k / h / p と P / Y など
	3. C言語の基本規則とプログラムの構造
      * C言語では「大文字・小文字」は厳密に区別される。
プログラム作成から実行の流れ
$$[\text{ソースファイル}] \longrightarrow (\text{コンパイル}) \longrightarrow [\text{実行ファイル}]$$
      * ソースファイル：テキストファイル（プログラムコード本体）
      * コンパイル：コンピュータが理解できる形式（.exe, .obj など）に変換
      * 実行ファイル：OS（Windows, Mac等）ごとに生成される
      * 統合開発環境 (IDE)：これらの一連の作業（作成・コンパイル・実行）をまとめて行えるツール。

構成要素
      * #include <stdio.h>：標準入出力ライブラリの読み込み
      * int main(void) { ... }：プログラムのメイン処理（波カッコ {} は必ず対にする）
      * printf("...");：画面に文字列を出力する関数
      * return 0;：プログラムの正常終了を示す
ファイル作成時の注意事項
      1. ファイル名：半角英数字のみ使用可能
      2. 禁止事項：全角文字 、途中の .（ドット）
      3. 命名規則：必ずアルファベットから始める
      4. 拡張子：末尾は必ず .c にする（例: hello.c）

構造の解説
構成要素
	解説
	#include <stdio.h>
	プリプロセッサ指示文。
stdio.h（Standard Input/Output ヘッダーファイル）を取り込み（インクルード）、printf 関数などの標準入出力機能を使用可能にします。
	int main(void)
	メイン関数。プログラムの実行開始地点となります。
	{ ... }
	プログラムの本体（ブロック）。この中に処理（文）を記述します。
	printf("...");
	画面に文字を表示するための関数（命令）です。
	return 0;
	プログラムの終了をOSに伝える文です（戻り値 0）。
	2. 構文ルールと書き方のポイント
(1) 文の区切り（セミコロン）
         * 各処理の末尾には、必ずセミコロン ; を付けます（日本語の句点「。」に相当）。
(2) 改行文字 (\n)
         * printf 内の \n（または環境により ¥n）は改行を表します。
         * 半角の ¥ と \（バックスラッシュ）は同じ意味です。
(3) インデント（字下げ）
         * {}（波かっこ）の中身は、Tabキー1個分（またはスペース2〜4個）のインデントを入れます。
         * 目的: 処理の階層構造を明確にし、コードを見やすくするため。
3. 補足・注意点
① return 文の記法
         * return (0); と書いても動作しますが、かっこは省略して return 0; と書くのが一般的です。
② ファイル名の付け方・ルール
         * 使用可能文字: 半角英数字、アンダースコア (_)
         * 禁止事項: 空白（スペース）、全角文字
         * 基本方針: アルファベット小文字を使用する
         * 例: 課題1_1.c  k1_1.c
4. 予習・次回内容（P.4, 5 課題1）
変数の宣言
            * 概念: プログラム内で扱う数値などのデータを入れる「箱」。
            * 整数型の宣言: int（integer）を使用し、変数を宣言します。
            * 例: int x;（整数を入れる変数 x を用意する）

3. プログラム例（例題 1.2）
#include <stdio.h>


int main(void) {
    int nasi, ringo, s;  // 変数の宣言


    scanf("%d %d", &nasi, &ringo);  // キーボードからの入力


    s = 150 * nasi + 190 * ringo;  // 金額の計算（代入演算）


    printf("梨 = %4d 円\n", nasi);
    printf("林檎 = %4d 円\n", ringo);
    printf("総額 = %4d 円\n", s);


    return 0;
}
4. プログラム解説・メモ
① 変数と宣言
               * int nasi, ringo, s;
               * プログラムで使う変数を宣言する（「宣言」と言う）。
               * 宣言しないと使えない！
               * 小文字で始める。小文字・数字が使用可能。
② 入力処理（scanf）
               * scanf("%d %d", &nasi, &ringo);
               * scanf はデータを取得（キーボード等からの入力）。
               * %d ：整数を受け取る指定（1つ目の %d は nasi へ、2つ目の %d は ringo へ）。
               * 変数名の前に & を付ける（&nasi, &ringo）。
③ 演算と代入（= 演算子）
               * s = 150 * nasi + 190 * ringo;
               * = （代入演算子）：右辺の計算結果（評価値）を左辺の変数に格納する（上書き代入される）。
               * 演算子：+, -, *, / など。
               * 優先順位：`*


プログラミング講義ノート
1. 実数と四則演算（C言語）
1.1 基本データ型と書式指定子
               * 実数（小数を含めた数値の型）
               * ※「整数」に限定されない、小数を含む数値を扱う。
               * double 型：実数型のひとつ（8byte / 2倍の精度 ※float型は4byte）。
               * 書式指定子
               * %d ： 整数
               * %f / %lf ： double 型を扱う時の記号（変換指定子）。
               * scanf や printf で使用（%lf は double の出入力用）。
               * 「実数を表示するときの記号」と覚えておけばOK。
1.2 %f の桁指定（実数の場合のケタ指定）
               1. 標準形：%N.Mf
               * 全体で  桁（小数点 . も含む）
               * 小数部  桁
                  2. 全体のみ指定：%Nf
                  * 全体を  桁で表示
                     3. 小数部桁数のみ指定：%.Mf
                     * 小数部を  桁で表示
例（課題集）：%5.1f
                        * 全体で 5 桁、小数部 1 桁で出力。
                        * 表示例：000.0
                        * ※全体が収まらないとき、小数部は守られ、指定された桁数に合わせてみはみ出して出力される（全体桁数は無視される）。
1.3 実数型定数の表現
表記
	型
	意味
	2
	整数型（int）
	整数値の 2
	2.0
	実数型（double）
	実数値の 2.0
	2. 演算と型変換（キャスト）
2.1 型同士の演算ルール
                        * 計算は各データ型ごとに行われる
                        * 整数同士の計算の答えは 整数 になる（例：double 型へ代入しても整数部分のみを取り出す）。
2.2 キャスト演算子（型変換）
                        * 構文：( double ) 変数 / 数値
                        * 動作： この計算のときだけ、指定したデータ型に変換される。

s = (double)r / n;  // r を一時的に double 型として計算
2.3 暗黙の型変換
                        * C言語の演算は 同じデータ型同士でのみ可能。
                        * 型が違うデータ同士の演算の場合、暗黙の型変換 が行われる。
                        * 優先度（型の階級）が高い方のデータ型に合わせて自動変換される。
                        * 階級： 整数型  実数型（double）
3. プログラムの図表現とフローチャート (10/07)
3.1 プログラムの図表現（流れ図）
                           * フローチャート：問題点がわかりやすく、最もよく使われている。
                           * その他の図表現：PAD など
                           * 厳密には、これらは 「アルゴリズム」 を表現するためのもの。
3.2 フローチャートの種類
                           * システムフローチャート
                           * プログラムフローチャート：ソースコードでできるプログラミングの流れをそのまま書こうとしたもの。
                           * その他

記号形状
	名称
	役割・補足
	長方形
	処理
	一般的な処理（代入、計算など）
	ひし形
	分岐
	条件分岐（if文など）
	六角形（上下平ら）
	反復
	繰り返し処理の開始/終了
	角丸長方形
	端子
	始端子 / 終端子（スタート / エンド）
	円形
	結合子
	処理の合流点
	二重線の長方形
	定義済み処理
	別途定義された関数や処理の呼び出し
	平行四辺形
	データ
	データの入出力
	六角形（横長）
	準備
	メインプログラムを実行する前に行う初期化等
	矢印 / 線
	線
	処理の流れ（※分岐のときは矢印を使う場合もある）
	※ システムフローチャートの記号（プログラムフローチャートではあまり使わない）
                           * 台形：手入力
                           * 凸型：表示

                                          * 関数呼び出し：sin(pi / 2.0) のように引数を与えて関数を呼び出す。

                                          * 引数（ひきすう）の指定：定数だけでなく、計算式（pi / 2.0 など）をそのまま渡すことも可能。
